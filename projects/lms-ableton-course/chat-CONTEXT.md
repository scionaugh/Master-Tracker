## Goals and Purpose
An 18-module Ableton Live / Psytech production course delivered via the ScioSound LMS. Each module pairs a technical skill (Ableton workflow, sound design, mixing, mastering) with a "Headspace" theme — a short creative-mindset/philosophy section that frames the technical content (e.g. beginner's mind, ear-eye relationship, performance flow, letting go of perfectionism). Source: `Course_Module_Overview.xlsx` — finalized 2026-06-10, all 18 modules scoped.

## Course Structure (Stages)
- **Stage 00 — Orientation** (M1): Ableton interface, audio prefs, waveform basics
- **Stage 01 — Foundations** (M2–M8): rhythm/Drum Rack, kick & bass, the five basic Psytech sounds, samplers/warping, harmony/inversions, melody/the tonic, Session View performance jam
- **Stage 02 — Arrangement** (M9–M12): Session→Arrangement transition, automation/energy, synthesis/modulation (risers), one-shots/FX
- **Stage 03 — Mixdown** (M13–M15): spectral balance (Search & Destroy EQ, SPAN reference), group processing/glue, peer feedback cycle
- **Stage 04 — Mastering & Release** (M16–M17): mastering chain to -14 LUFS, export/release ritual
- **Stage 05 — Performance** (M18): performance styles, USB vs. Ableton liveset — still only a one-line summary plus "DJ for 1 hour" homework, no full module structure

## Key Decisions Made
- Modules 1–17 are now fully built out against a shared template: Ableton Instruments, Ableton Audio FX, hands-on Activity, Headspace Theme + Summary, Learning Outcomes, Technical Outcome, Homework, Glossary Terms, and a "Nerd Section" technical deep-dive. Module 18 is the one exception (see Stage 05 above).
- Modules build cumulatively on a shared project: signal chain/groups established in M2 (Drum Group, Melody Group) are reused and refined through to mixdown (M13–14).
- "Nerd Section" deep-dives are optional/supplementary technical content (e.g. M1 covers sample rate/digital conversion, M3 covers phase/interference via oscilloscope) — separate from the core lesson flow.
- Recurring teaching device: ear-eye relationship (matching what's heard to what's seen on Spectrum/waveform), introduced in M1 and built on through M2–M3.

## Constraints and Dependencies
- Delivered via the ScioSound LMS platform (`../lms`), which currently has only example modules — this course's content has not been implemented in the LMS yet.
- Possible companion relationship to the Sound Science course (`../lms-sound-science-course`) — several "Nerd Section" topics (sample rate, phase/interference, harmonics) overlap with Sound Science lessons, but the relationship between the two courses hasn't been defined.
